# Browsing Map

A full-stack application that captures browser activity through a Chrome Extension and visualizes browsing locations on an interactive world map.
![Uploading image.png…]()

## Tech Stack
- React
- Vite
- Express.js
- SQLite
- Chrome Extension (Manifest V3)
- GeoIP Lite

## Features
- Real-time URL capture
- DNS resolution
- GeoIP location mapping
- Interactive world map
- Country heatmap
- Time travel replay
- SQLite persistence

## Architecture
Chrome Extension → Express API → DNS → GeoIP → SQLite → React Dashboard

## Setup
npm install
npm run dev
